Descripción del Proyecto
Este repositorio contiene la documentación y evidencias correspondientes a la práctica **S4: Crear tu Primera Base de Datos en PostgreSQL usando Docker y DataGrip. En esta práctica se configuró un entorno de base de datos relacional PostgreSQL utilizando contenedores en Docker Desktop**, administrado a través del IDE **JetBrains DataGrip** y verificado tanto mediante consola SQL como por consola interactiva de psql en Docker.
